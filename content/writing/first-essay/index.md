## A place for an idea

Write in Markdown and let Zola turn it into HTML. Paragraphs, *emphasis*, [links to the portfolio](@/_index.md), and headings work without any client-side code.

> Start with the thing you want to say. Give it enough space to be understood.

### Working notes

- One clear idea per paragraph
- Examples where they help
- Links to sources and related work
